# 🛸 Crónicas de un Disociado en San Pedro — Universo Genio Maluco

Web cómic animado de la rutina de stand-up de **Genio Maluco**, acompañado de su **Biblia de Diseño Gráfico, Bocetos de Esqueletos, Frames Selfie y Base de Datos de Personajes**.

Un treintañero (37 años, 1.68 m, gordito pero macizo por jugar básquetbol, barba tupida, lentes oscuros redondos y su infaltable gafete) sale a la hora del almuerzo en San Pedro de Montes de Oca, se disocia por el *bochorno*, sobrevive a la señora de la chancleta, paga un SINPE de 4 tejas, descubre un platillo volador... y termina en una reunión de viernes a las 4:50 p.m. con pizza.

## ▶️ Ver el cómic y la Base de Datos

- 🪪 **Biblia Gráfica, Bocetos & Base de Datos de Personajes:** [`personajes.html`](personajes.html)
